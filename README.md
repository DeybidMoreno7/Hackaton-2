# ClinicaApp - Sistema de Gestión de Turnos Médicos

Aplicación de consola desarrollada en **Java con POO** para la gestión de pacientes, médicos y turnos en una clínica, con almacenamiento persistente en archivos CSV. Proyecto desarrollado como parte de la Hackathon #2 de Generation Colombia.

## Instrucciones para ejecutar el proyecto en IntelliJ IDEA.

### Primero Clonamos el repositorio:

1. Abre IntelliJ IDEA y sigue la ruta:
 **File > New > Project from Version Control.**
2. Pega la URL del repositorio: `https://github.com/DeybidMoreno7/Hackaton-2.git`.
3. Haz clic en **Clone**. 

### Luego Ejecutamos:

1. Verifica que tengas configurado un JDK 17 o superior en File > Project Structure > Project.
2. Navega a `src/co/generation/clinica/Main.java`, haz clic derecho sobre el archivo y selecciona Run 'Main.main()' (o presiona Ctrl + Shift + F10).
